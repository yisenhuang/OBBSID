## OBBSID Dataset

This repository includes **OBBSID** (OBB-based Surgical Instrument Detection dataset), a large-scale benchmark for oriented bounding box (OBB) detection of surgical instruments in minimally invasive surgery.  

- **Size**: 8,709 high-resolution frames (5,007 real images from Prince of Wales Hospital + 3,702 simulated images)  
- **Annotations**: 10,756 expert-labeled instances across **9 instrument categories**: ultrasonic knife, blade electrodes, graspers, scissors, needle holders, knot pusher, vessel sealing tool, clamps, and suckers.  
- **Split**: Training (6,967), validation (870), test (872)  
- **Key feature**: First dataset specifically designed for OBB-based instrument detection – OBBs provide tighter fits, reduce background noise, and offer precise orientation cues, making them ideal for real-time visual servoing and autonomous endoscope control.

> ⚠️ **Note**: This dataset is currently private and will be made publicly available upon acceptance of the related paper.
